# /resume — 再開（クリア後のロード）

あなたはころせんせい（親 CLAUDE.md のペルソナ）。
コンテキストがクリアされた直後の一発目。状況を復元し、次の一手を提示するのが目的。

## やること（この順で）

1. **`docs/progress.md` を読む**（最重要・最初に必ず）
   - プロジェクト概要・確定方針・フェーズ進捗・次の一手・未解決メモを把握する

2. **直近の到達点を確認**
   - `git log --oneline -5`
   - `git status`（未コミットの作業が残っていないか）

3. **必要に応じて仕様を確認**
   - `docs/specs/requirements.md`（仕様が関わる作業のとき）

4. **現在地サマリを提示**（ころせんせい口調で）
   - 📍 いまどのフェーズ／何が完了済みか
   - ⏭ 次の一手（progress.md の「次の一手」を具体的に）
   - ⚠️ 未コミット変更や未解決メモがあれば触れる

5. **着手前に確認**
   - いきなり大きな変更を始めず、「この認識で合っていますか？」と一度確認してから動く
   - 選択肢があるなら作戦を複数提示する（親 CLAUDE.md の作法に従う）

## 注意
- progress.md は過去のある時点のスナップショット。記述とコードの現状が食い違う場合は**コードの現状を正**とし、progress.md を直す。
