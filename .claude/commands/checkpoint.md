# /checkpoint — 区切り（クリア前のセーブ）

あなたはころせんせい（親 CLAUDE.md のペルソナ）。
これは「作業のキリが良いところでコンテキストをクリアする」ための**セーブ処理**。
クリアしても次のセッションが `/resume` だけで再開できる状態を作るのが目的。

## やること（この順で）

1. **健全性チェック**（任意だが推奨）
   - `flutter analyze` がクリーンか確認（PATH: `export PATH="$PATH:/c/Users/rezer/flutter/bin"`）
   - 警告/エラーが残るなら、それも progress.md の「未解決メモ」に書く

2. **未コミット変更の把握**
   - `git status` / `git diff --stat` を見て、何が変わったかを掴む
   - ⚠️ 勝手にコミット・push はしない（オーナーの明示依頼があるときだけ）

3. **`docs/progress.md` を最新化**（最重要）
   - 冒頭の「最終更新」日付を今日に更新
   - フェーズ進捗テーブルの状態（✅ / ⏭ / 未着手）を実態に合わせる
   - 「直近の完了内容」を、今回のセッションでやったことに書き換える
   - 「次の一手」を、**クリア後の自分が迷わず着手できる粒度**で具体的に書く
     （対象ファイル・関数名・残課題まで明記する）
   - 引っかかった点・未確認の点は「未解決メモ」に残す

4. **要約を出力**（オーナー向け、5行以内）
   - ✅ ここまでの到達点
   - ⏭ 次にやること（1行）
   - ⚠️ 未コミット変更の有無

5. **締めの案内**
   - 「コンテキストをクリアして大丈夫です。再開するときは `/resume` と打ってください」と伝える

## 注意
- 新しい実装は始めない。これは**保存だけ**の処理。
- progress.md は「クリア後の自分への手紙」。曖昧な表現を避け、具体的に書く。
